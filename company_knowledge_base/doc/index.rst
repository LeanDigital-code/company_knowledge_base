Knowledge Base Pro
==================

Knowledge Base Pro is an advanced internal knowledge management module for Odoo 18 Community.

Installation
------------

1. Copy the ``company_knowledge_base`` folder into your Odoo addons path.
2. Restart Odoo.
3. Update the Apps list.
4. Install ``Knowledge Base Pro``.

Configuration
-------------

After installation, configure:

* Knowledge Base categories
* Article templates
* Departments / areas
* Security groups
* Quality rules
* Review reminders
* Notification settings
* Feedback activity settings

Open module settings from:

``Knowledge Base > Configurazione > Impostazioni Knowledge Base``

Main Features
-------------

* Structured articles
* Categories, subcategories and tags
* Approval workflow
* Version history
* Version comparison and restore
* Quality checks
* Feedback management
* Favorites and reading history
* Reading acknowledgements
* Notifications
* Related articles
* Portal publishing
* CSV import
* CSV, HTML and PDF export
* Smart dashboard

User Roles
----------

* Knowledge Base Reader
* Knowledge Base Editor
* Knowledge Base Manager
* Knowledge Base Administrator

Support
-------

For support, contact the vendor email configured in the module manifest.
